How to use this site

  1. Work through each module in order — concepts build on each other.
  2. Copy the YAML examples into your own repository and run them.
  3. Complete the hands-on exercises at the end of every module.
  4. Take the practice quizzes to test your readiness.
  5. Review the flowcharts before the exam to visualize job flows.
